# 麻雀リーグ戦アプリ 要件・設計メモ

作成日: 2026-08-18（/grill-me の結果）

## 1. 概要

- 10人・5人×2チームのリーグ戦の戦績管理アプリ
- 認証なし。URLを知っている身内だけが使う前提
- スマホファースト

## 2. 機能

### 2.1 半荘登録（唯一の書き込み機能）
- 入力: 日付、4人のメンバー選択、各人の素点
- バリデーション
  - 4人はリーグ所属メンバーで重複なし
  - **各チーム2人ずつ（2-2固定）** を必須
  - 素点合計 = 25,000 × 4 = 100,000（供託リーチ棒はトップ取りで精算済み前提）
  - 素点は100点単位、負数可（箱下精算あり）
- 編集・削除は誰でも可（確認ダイアログ）。削除は `deleted_at` の論理削除

### 2.2 リーグ戦績
- チーム合計pt（メンバーptの単純総和。半荘数の上限なし）
- 個人ランキング（合計pt）
- 半荘一覧（日付順、削除済みは非表示）
- 累計pt推移グラフ（チーム・個人）

### 2.3 個人成績
- 合計pt / 半荘数 / 平均pt / 平均順位 / 1〜4着回数と率 / トップ率 / ラス率 / 最高・最低素点
- 累計pt推移グラフ

### 2.4 ルール確認ページ
- リポジトリ内 Markdown を静的表示
- ポイント換算部分（持ち点/返し/ウマ/オカ）だけはDBのリーグ設定値から動的に差し込む

### 2.5 管理系
- アプリに管理UIは作らない
- メンバー・リーグ・チーム・所属・リーグ設定は Supabase Dashboard / seed SQL で直接投入

## 3. ポイント計算仕様

- 素点のみDBに保存。pt・順位はフロントで都度計算（純粋関数＋ユニットテスト）
- pt = (素点 − 返し点) / 1000 + ウマ (+ トップはオカ)
- 小数第1位まで保持
- **同点時はウマを折半して山分け**（トップ同点ならオカも折半）。座順の記録は不要
- リーグ設定（DB）デフォルト
  - 持ち点 25,000 / 返し点 30,000（オカあり）/ ウマ 10-30（1-3）
  - トビ終了なし、箱下精算あり

## 4. ルール（ルールページの元ネタ）

東南 / アリアリ / テンパイ連チャンなし / 持ち点25000 / トビ終了なし / 箱下精算あり / オカあり / ウマ1-3 /
ノーテン罰符3000 / 積み棒300 / 鳴き: ポン優先 / 同時ロンは頭ハネ / 30000点以上のオーラスのあがりやめなし /
流し満貫あり / 九種九牌あり（親流れ）/ 四家立直あり（続行）/ 四風連打あり（親流れ）/
四槓子流れ: 流れない（カンはできない）/ パオあり（大三元・大四喜・四槓子）/ 引き上げ満貫あり /
加槓・大明槓: 新ドラ先めくり / 多牌: 満貫払い / 少牌: 和了放棄

## 5. データモデル（案）

```
leagues        id, name, start_point, return_point, uma_2nd, uma_1st(=uma_top), oka, created_at
teams          id, league_id, name
members        id, name
league_members league_id, member_id, team_id
games          id, league_id, played_on(date), memo, created_at, deleted_at
game_results   id, game_id, member_id, raw_score(int)   -- 1 game につき4行
```

- リーグ > 半荘（日付付き）。「節」テーブルは作らない
- 複数リーグ存在時はトップでリーグ選択

## 6. 技術スタック

- フロント: Vite + React + TypeScript（SPA）
- UI: Tailwind + shadcn/ui、グラフ: Recharts
- DB: Supabase (Postgres)。supabase-js でクライアントから直アクセス
  - anon key 公開・RLS は全許可（身内前提のリスクを許容）
- ホスティング: Cloudflare Pages
- ツール: bun / Vitest / **oxlint + oxfmt** / Supabase CLI（`supabase/migrations`、`supabase gen types`）
  - 既存 `.claude/hooks/biome-format.sh` は oxfmt に差し替える
