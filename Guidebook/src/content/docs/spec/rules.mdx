<Aside type="note">
この内容がアプリの「ルール確認ページ」に静的表示される。ポイント換算まわり（持ち点・返し点・ウマ・オカ）だけはDBのリーグ設定値から動的に差し込む。
</Aside>

## 基本

| 項目 | 内容 |
|---|---|
| 荘 | 東南戦 |
| 喰いタン・後付け | アリアリ |
| 持ち点 | 25,000 |
| 返し点 / オカ | 30,000 / あり |
| ウマ | 1-3（10-30） |
| トビ終了 | なし |
| 箱下精算 | あり |
| テンパイ連荘 | なし |
| **返し点**以上のオーラスあがりやめ | なし |

<Aside type="note" title="あがりやめの基準点は「返し点」と同じ値を使う">
「◯点以上のオーラスあがりやめ」の◯は、**`leagues.return_point` を差し込む**（既定 30,000）。

麻雀のルールとしては、あがりやめの基準点を返し点と**別に**決めることもありうる。ただしこのリーグは「なし」なので値が表に出る場面が無く、**別のカラムを増やすより返し点に結びつける方が安い**と判断した。

**実装（`RulesPage.tsx`）はこの前提で書かれている。** 将来「あがりやめ**あり**」に変えて、かつ基準点を返し点と別にしたくなったら、`leagues` にカラムを足すことになる。
</Aside>

## 役・責任払い

| 項目 | 内容 |
|---|---|
| パオ | あり（大三元・大四喜・四槓子） |
| 切り上げ満貫 | あり |
| 数え役満 | **あり**（13翻以上は役満） |
| 連風牌 | **2翻**（Mリーグ準拠） |

<Aside type="caution" title="まだ決めていないもの">
**ダブル役満**（国士無双十三面・四暗刻単騎・純正九蓮宝燈・大四喜など）の扱いは**未定**。

役一覧のページは**すべて役満1つ分**として書いてある。採用するなら、ここに書いてから一覧を直す。
</Aside>
